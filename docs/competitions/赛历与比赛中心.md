# 赛历与比赛中心

## 已接通的流程

318 年 1 月 1 日开档 → 按日期推进所有赛事 → 十二月结算 → 319 年使用升降级后的名单生成赛程。每个赛季 268 家俱乐部、16 个联赛级别，正式比赛共 4,759 场：联赛 4,412、五个地区杯 247、星冠季后赛与十组升级附加赛 37、全球冠军杯 63。另有 68 个轮空签位，不算出场和正式比赛。

| 日期 | 内容 |
| --- | --- |
| 1 月—2 月 | 冬季注册窗口；1 月 20 日生成星冠 48 签顺序 |
| 2 月 | 季前备战期 |
| 3 月—11 月初 | 16 级联赛双循环、地区杯前五轮，六月暂停国内赛事 |
| 6 月 3 / 7 / 11 日 | 全球杯小组赛 |
| 6 月 16 / 20 / 24 / 28 日 | 全球杯十六强至决赛 |
| 7 月 | 夏季注册窗口；国内赛事恢复 |
| 11 月 8 / 15 / 22 日 | 星冠八强、半决赛、决赛 |
| 11 月 15 / 22 日 | 升级附加赛半决赛、决赛 |
| 11 月 29 日 | 五个地区杯决赛 |
| 12 月 1 日 | 冠军、升降级与下一年全球杯资格结算 |
| 12 月 2—31 日 | 休赛；完成全年后进入新赛季 |

统一星球标准时间 19:30 开球。殖民历沿用公历月长、星期及闰年结构。国内赛历以周三和周六为候选日，先分配杯赛专用日，联赛按各级轮数分布在其余日期，各级末轮在同一天结束。所有赛事合并后最短间隔三天，包括六月全球杯前后。自动测试覆盖 318—345 年不同星期和闰年。

## 赛果与晋级

- 未开始的积分榜是零场零分；附加赛以“常规赛第 N 名”展示，前序结果确定后才解析球队。
- 世界共用一个时钟。筛选只改变显示；推进时间仍完成所有地区同日赛事，不能挑某队单独刷战绩。
- 比分由现有第六版逐事件比赛引擎生成，淘汰赛沿用加时和点球，不通过排名强制判胜。
- 下级前二直升，第 3—6 名附加赛决出第三席；上级末三降级。十个级别接口每年合计 30 升、30 降。星冠 16 队不变。
- 下一年全球杯按本年顶级联赛排名分配 32 席；星冠用常规赛榜。318 年首次参赛者明确标为“创始赛季资格名单”，不冒充 317 年赛果。
- 选秀顺序从次年起使用上一年星冠真实逆战绩。此版本只生成签位，不执行选人或签约。
- 冠军、最终排名、升降级、全球杯资格及所有比赛报告保留在原赛季档案。

## 球员与纪律

同队后续比赛读取上一场留下的体能和伤病；休息日每天恢复 7 点体能、扣减一天伤期。比赛中受伤记录、累计五黄和红牌停赛进入存档。纪律按赛事独立累计，球队的下一场对应赛事执行停赛。新赛季清黄牌，剩余禁赛顺延；升降级时联赛禁赛跟随新级别。球队阵容页读取当前体能、伤病与联赛归属。

## 存档与一致性

- `src/competitions/calendar.js`：全年排期与日期工具。
- `runtime.js`：独立于页面的赛季状态、依赖解析、正式比赛、排名、结算和跨季。
- `store.js`：IndexedDB 保存当前赛季与历史赛季。按比赛日原子提交；暂停或当日错误不会留下半个比赛日，之前成功保存的日期保留。
- Web Locks 串行处理多标签页写入；进入写锁后重新读取最新存档，避免旧页面重复推进。
- 当前真实引擎审计单季 JSON 约 15.8 MB，使用 IndexedDB，避免 localStorage 容量不足。历史按年度存储，无静默清理或覆盖。
- 存档版本不兼容、结构错误、磁盘存储失败显示错误，禁止悄悄重建游戏。
- 旧 `#leagues/.../table`、`fixtures`、`cup`、`playoffs` 地址转到同一比赛中心，不再维护独立试算结果。

## 界面与参考

沿用深绿和金色。主页面按日期分组显示对阵与比分；可筛赛季、赛事、球队。全年视图含十二个月概览和具体月历；积分表标记升降级/晋级区；淘汰赛按轮次显示签表；点击比分打开比赛统计和关键事件。

参考以下官方信息组织方式，未复制标识、商业素材或现实赛制：

- [NBA 赛程](https://www.nba.com/schedule)：日期导航与球队筛选。
- [英超比赛](https://www.premierleague.com/en/matches/premier-league/2026-27)：赛季、比赛与积分榜入口。
- [西甲赛果](https://www.laliga.com/en-GB/laliga-easports/results)：赛程、赛果和排名分栏。
- [德甲比赛日](https://www.bundesliga.com/en/bundesliga/matchday)：按日期排列时间、对阵及俱乐部筛选。
- [意甲赛历](https://www.legaseriea.it/serie-a/calendario-risultati)：按赛季和比赛日导航。
- [法甲赛程](https://ligue1.com/en/calendar/ligue1)：比赛、赛果、排名导航。
- [欧冠赛程](https://www.uefa.com/uefachampionsleague/fixtures-results/)与 [NBA 季后赛](https://www.nba.com/playoffs/2026)：赛程与淘汰赛阶段分开组织。

## 验证与当前范围

- `npm run check`、`npm test`：语法和回归，包括七项赛历/跨季测试。
- `npm run audit:season`：318、319 两个连续赛季，共 **9,518 场真实引擎比赛**。逐月序列化恢复；检查每队完赛、比赛间隔、进失球守恒、晋级、升降级和次年名单。报告：`artifacts/season/audit.json`。
- 318 年场均进球 2.777、319 年 2.836；二者最短休息都为三天。这是模拟审计数据，不是与职业赛事做过统计拟合的证明。
- 浏览器验收使用 `localhost:4318` 独立测试存档；用户的 `127.0.0.1:4318` 存档保持初始日期。

此阶段实现赛事赛历和持续赛季。注册、选秀、转会窗口已排期，转会合同、选秀选人、球员年度成长/退役、球场共享、旅行和天气尚未接入。接手俱乐部后，日期推进停在本队比赛日，可在经理首页进入正式比赛布阵、指挥或委托至终场；其他球队自动运行。详见《经理与正式执教》。报名人数与本地培养名额的审核也仍待实现。
