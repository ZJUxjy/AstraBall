# 税收与资金流

2026-09-17，税务版本 1。星元为虚构世界货币，下列税率是本项目的初始政策参数，并非任何现实国家税法的复刻。

## 三方结算

转会成交价按税前金额记账，卖方缴纳 5% 转会交易税。例如买方支付 1 亿，卖方入账转会收入 1 亿、交易税支出 500 万，现金实际增加 9,500 万；卖方所在地税库增加 500 万。买方不再重复支付同一笔税。自由签约转会费为零，转会交易税也为零。

球员合同工资、签字费、解约补偿均为税前金额。俱乐部支出由球员实得与代扣所得税组成，个税不重复列为俱乐部额外费用。球员年内跨俱乐部、跨地区签约仍合并同一年度个人收入，代扣税款汇入付款俱乐部所在地税库。当前各地区采用相同税率，税前更优的报价税后仍然更优。

个人所得税按年度累计收入分档计税，每次付款补扣新增税额，整数星元向下取整：

| 年收入区间 | 该区间边际税率 |
|---|---:|
| 0—6 万 | 0% |
| 6 万—30 万 | 10% |
| 30 万—100 万 | 20% |
| 100 万—500 万 | 30% |
| 500 万—2,000 万 | 40% |
| 超过 2,000 万 | 45% |

累计收入先使用本年度免税额度，随后随付款进入更高税档；并非每周重新给一份免税额度。跨年归档后才重置。当前没有其他收入来源和税收抵扣，因此累计代扣等于该年度模型内最终税额。界面的税后周薪是仅含全年工资、不含签字费与补偿的平均估算；实际个人账本以真实付款为准。

原有工资超额税继续单列，由俱乐部额外承担，汇入所属地区的联盟资金账户。它是联赛约束，不替代个人所得税。政府税库与联盟资金分别记录，不混为球员收入。

## 对账与存档

每个俱乐部保留税前费用、转会税，以及代扣个税和球员实得的备查账。每个球员保留年度收入、税款、净收入和历史年度。每个地区保留政府转会税、政府个税和联盟超额税的年度与累计收款。

检查同时要求：转会双方税前金额一致；卖方实收加转会税等于成交额；球员实得加个税等于税前支付；地区收款与俱乐部税款一致；个人年度个税符合累进税率；年度、历史与累计账目一致。个人净收入是累计实得记录，不等同于扣除消费后的银行余额。

新建生涯使用独立数据库 `astraball-seasons-rules-v2-economy-v3-cities-v1-bidding-v1-tax-v1`。旧生涯和既有模拟报告保持原规则，不追溯补扣税款。税务开启后适用于手动签约、AI 竞价、注册系统的交易、自由签约、续约、解约与日常工资。

## 真实性边界

税务初版将政府及联盟收入留存在账上。后续地方体系版本已接入公共支出、基层与青训拨款、有限银行信贷、托管和破产递补，见[完整经济循环与地方体系](完整经济循环与地方体系.md)。本篇的一季税务报告保留初版结果。企业利润税、交易税抵扣、经纪费、雇主社保、分期转会和球员资产摊销尚未建模；居民和企业仍使用外部总量部门，不能称为完整宏观经济。

扩张俱乐部数量前，应先建立下级联赛和独立俱乐部账户，并保持区域转播与商业资金池不因球队数量增加而等比例凭空增发。相关规模审计见 [俱乐部体系规模](../world/俱乐部体系规模.md)。
