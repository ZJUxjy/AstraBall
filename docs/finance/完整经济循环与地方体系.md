# 完整经济循环与地方体系

这版把省、市球队接入同一赛历、资金账本和球员身份系统。新游戏默认启用；原有存档保留原规则，不在中途无声扩容。源码入口是 `createSeason({worldModel:true})`，页面入口是“地方足球与经济”。

## 规模与比赛

| 层级 | 联赛数 | 每联赛球队 | 球队总数 | 每队联赛场次 |
|---|---:|---:|---:|---:|
| 原职业赛事 | 沿用既有赛制 | 沿用 | 217 | 沿用 |
| 省级职业 | 36 | 12 | 432 | 22 |
| 城市半职业 | 108 | 8 | 864 | 14 |
| 城市业余 | 108 | 16 | 1,728 | 30 |

总计 3,241 支参赛球队。新增地方体系初始每队 25 人，共 75,600 名球员，每季 36,720 场双循环比赛。省级球队按城市人口、经济需求与同城竞争分布；城市基层联赛保留固定容量。地区财富差异继续影响球队预算。

每场地方比赛真实生成比分、双方首发、进球、出场分钟和积分，主场比赛产生门票收入。地方引擎使用确定性随机与球队能力计算比分；尚不计算完整战术、伤病、换人和替补轮换。原职业赛事继续运行完整比赛引擎。

每省三座城市的半职业冠军升省级，省级末三名降级；每城业余冠军与半职业降级队互换。现有国家级/地区级联赛保留原席位制度，地方球队在原职业俱乐部解散时可递补。不是把既有封闭联赛整体改为开放升降级。

## 球员身份与劳动收入

- 地方球员有姓名、出生年、位置、能力、潜力、合同、工资和逐年比赛记录。年龄、潜力差距、出场时间与公共设施影响成长；老将衰退，38 岁退休；青少年补充缺额。
- 地方之间可以有偿转会，职业俱乐部可以从地方买人，被职业队释放的自由球员可以回到半职业或省级职业。整个过程保留球员 ID 与累计纳税记录。
- 原职业联赛保留多队竞价；地方市场按能力、预算、位置覆盖与合同工资报价，尚未采用同等深度的竞价模型。
- 业余球员不领职业工资；半职业与省级职业采用不同基准工资。地方球队升降级不直接抹去未到期合同。
- 职业球员个人工资有上限：不超过本队经营收入预算的 3.5%（折合顶级俱乐部年薪约 3000—4000 万），并有 8 万/周的地板线保证小俱乐部开得起本级别工资。竞价可以推高转会费，合同工资统一封顶。
- 资金不足时只支付实际可付工资，剩余形成员工应收/俱乐部应付。个税只从实付款代扣；偿还欠薪时才触发对应个税。

## 资金来源与税收去向

地方地区收入池固定按人口与经济权重生成，地区内球队按级别和城市人口分配。增设球队会分摊收入池，不会按球队数量无限增发商业收入。地方初始预算中，82% 来自商业收入、18% 来自比赛日；运营预算为收入的 36%，初始工资预算上限为 55%，转会预算为 12%，开局现金为 30%。这些是虚构世界的可调模型参数，不是现实法规或实证统计。

原有转会税、球员累进个税和联盟奢侈税继续生效。转会费由买方流到卖方，卖方支付 5% 转会税；球员税前实付收入分成税后所得和政府税款，同一笔税款不会从俱乐部重复扣除。详细税率见《税收与资金流》。

公共部门按月使用实际已收税款：

- 政府新增个税与转会税收入的 60% 支出：其中约 5% 收入用于基层拨款、10% 用于设施、45% 用于公共服务；其余保留。可用余额不足时以余额为限。
- 联盟新增奢侈税收入的 30% 用于地方青训拨款，其余保留。
- 设施累计投入可提高地方年轻球员成长效率，最高加成 25%。
- 托管救助只能使用政府或联盟剩余资金，拨款同时扣除公共余额、增加球队现金；同一次托管不会重复领款。

## 贷款、逾期与托管

四个地区银行各有 10 亿星元初始资金。贷款实际减少银行现金、增加球队现金；还本与付息实际反向结算。每笔贷款独立记录本金、还款与损失。

- 总授信不超过预计年经营收入的 35%，还受银行剩余现金约束。
- 年利率 6%，按实际经过天数计息；分 36 个月还本，提前还款减少剩余本金。
- 月结先处理员工及运营应付款，再处理债务。无法付款记录欠息和逾期，不把负现金当作已经付款。
- 现金不足可在授信内补充周转贷款；出现欠款、持续逾期且无法续贷时进入托管。
- 联盟优先承担有预算的救助，其次政府；资金不足会记录无资助的托管，不能无限兜底。
- 托管限制引援；恢复足够现金、清欠并归还本金后可退出托管。
- 贷款流入、还本属于融资现金流，不作为经营盈利或财政亏损考核中的经营收入。

## 解散与真实递补

托管球队可以安排季末解散；长期不能清偿的球队也会触发季末处置。本季比赛完成后统一换位，避免中途删队破坏赛程。

1. 结算能偿还的员工与其他应付款，再核算剩余合同员工赔偿；实际支付与未支付债权分别记录。
2. 剩余现金偿还银行，无法收回的本金和欠息进入债权损失记录。
3. 球员解除原归属进入自由市场。原球队身份、往年比赛与债权档案保留。
4. 原职业联赛从本地区省级职业球队中按实际名次与财务状态选取递补队。递补的是另一支球队及其原球员，不是把破产队改个名字。
5. 地方空位继续由真实下级队递补，最低层由新社区队登记。新社区队从释放球员和业余市场组队，开局现金为零，不继承破产队旧名义。
6. 生成下一季正常赛程；原经理若执教解散球队则结束任职。

## 俱乐部声望

全部 3,241 家俱乐部共用 50—9999 的声望值。皇室俱乐部约 9200—9500，是唯一初始超过 9000 的俱乐部；其余职业俱乐部按商业基础与联赛层级分布在约 600—7500；地方俱乐部按层级初始化：省级职业约 1800、城市半职业约 900、城市业余约 400，另加确定性小幅差异。

- 每场正式比赛按零和方式交换声望：胜方从对手处取得，差距越大爆冷收益越高；平局使双方向中间靠拢。职业与地方赛事使用同一规则，单场幅度有上限。
- 赛季结算时声望向所属级别锚点缓慢回归（大都会级 9500、一级 8000、二级 5800、三级 4000、四级 2600，冠军趋向锚点、榜尾趋向一半），因此只有大都会级顶级俱乐部能长期维持 9000 以上。
- 升降级在赛季结算时一次性增减（升级 +400、降级 −400）；地方球队递补进原职业联赛时保留已积累的声望，新登记社区队按业余初始值开始。
- 原职业俱乐部的声望继续影响下一年赞助、商业收入与预计比赛日规模；地方声望暂不参与收入分配，只用于排序与强度参考。
- “世界资料 → 俱乐部排名”按声望列出全部成员俱乐部，可按大区、层级与名称筛选；省市联赛表同步显示各队声望。

## 验证与当前边界

专项测试覆盖固定地区收入池、逐场赛果和分钟、双向流动、实际支付与欠薪、有限公共救助、贷款利息、地方解散和原职业联赛递补后生成新赛程。普通存档校验也会对地方资金、银行本金、税款、比赛记录及联赛席位进行核验。

完整运行命令：

```sh
node scripts/football/audit-finance-history.mjs --world --years 3 --workers 4 --out artifacts/finance-history/<新目录>
node scripts/football/audit-world-economy.mjs artifacts/finance-history/<同一目录>
npm run check
npm test
```

每次模拟保存冻结源码与哈希、季度检查点、逐季赛果及账本。现金对账涵盖所有俱乐部、银行、税库、公共拨款、球员税后收入和外部运营服务支出。受控破产压力实验单独记录，不混入自然赛季统计。

这补齐了游戏内的足球财政循环，但不等于居民和企业的完整宏观经济：赞助商、观众收入与服务业仍是外部总量部门；公共服务支出尚无逐户消费或生产反馈；地方比赛与交易比原职业赛事轻量。3,241 家是可运行的代表性金字塔，仍非 500 亿人口对应的全量足球普查。长期财富分化和球员成长还需要基于这套新体系重新做十季以上校准，不能沿用旧 217 队报告当作新版结论。
