# 转会竞价与工资竞争

2026-09-17，竞价第 1 版。适用于新建的注册表生涯；已有存档没有 `economy.biddingVersion: 1` 时继续使用原定价。

## 价格来自实际买方

旧市场使用能力、年龄和剩余合同计算转会费，买方通常按本队薪资水平或原工资加 5% 签约。球队之间没有互相抬价；常规买人还存在“超过联赛固定能力上限不能签”的限制。因此财富积累未能充分转化为球星身价和工资竞争。

现在先形成卖方转会底价和球员工资底线，再收集有真实阵容需求、注册席位和支付能力的球队报价。球员能改善同位置前两名深度，或填补位置和人数缺口时，AI 才参与竞争。首选球员的替代成本高于普通替补，但在卖方仍有足够阵容和位置覆盖时，可以被高价买走。取消新市场的固定“能力高于联赛水平 11 点就不能买”限制。

球队的最高可接受溢价取决于可支配现金相对经营收入的规模、位置提升幅度，以及同位置同等能力球员的稀缺程度。所有上限先通过工资额度、即时资金、经营资金预留和完整合同期限的工资承诺检查。无法支付、没有名额、缺乏位置需求或不符合注册规则的球队不会成为抬价者。

竞价使用确定性的共同倍数：在转会底价和工资底线上一起加价，最高可承受上限者胜出，以次高上限再加 0.02 倍成交，并且不超过自己的上限。只有一家有效买方时，使用底价和工资底线。各队实际愿意支付的基础工资也会成为球员的共同最低要求，避免卖方得到更高转会费时球员反而接受较差工资。这是对俱乐部、球员两方谈判的简化，不是完整的多轮人工谈判系统。

每周先让各队提出最多两名优先目标，再按目标当前能力与稳定 ID 排序处理。每笔成交后重建资金和阵容状态，后续报价不能使用已经承诺的资金。经理本队不会被自动加入竞价或自动出售；手动查看和接受报价走相同清算与预算检查。

## 积存现金、工资和合同

- 可用引援额度保留原年度预算，再允许动用超过半年经营收入储备的累计现金的 35%；已经花费的引援资金只扣一次。最终仍须满足经营与工资资金预留。
- 竞价工资进入真实合同，按日计提。续约参考可以成交的外部薪资报价，俱乐部留住受追捧球员也要面对工资竞争；原有续约至少加薪 5% 的底线仍保留。
- 已签合同不因别处发生高价转会而自动改写。工资上涨发生在签约、续约等实际合同事件上。
- 自由球员转会费始终为零，竞争体现在工资和相应签字费上。
- 卖出球员获得的转会费留在卖方账户，可用于下一轮买人。转会费在全体俱乐部之间守恒；工资和签字费支付给球员，才会离开俱乐部现金池。
- 没有按年份统一乘通胀系数；竞争者变少、资金减少或需求消失时，竞价溢价可以下降。原有财政审查和工资约束继续执行。

交易保存参与球队、各自报价上限、次高报价方、起始条款和成交倍数。合同页面显示竞价球队数、溢价及续约参考的外部周薪。

## 验证与复现

受控实验固定同一名能力 93.4 的球员，主买方现金 50 亿，只改变竞争者的现金。其他球队没有可用工资额度，全部金额为星元。

| 竞争者现金 | 有效买方 | 转会费 | 周薪 |
|---|---:|---:|---:|
| 0 | 1 | 1.17 亿 | 85.37 万 |
| 5 亿 | 2 | 2.47 亿 | 180.56 万 |
| 20 亿 | 2 | 5.58 亿 | 408.53 万 |

这是机制对照，不是赛季平均成交价。每组分别从同一初始状态成交，检查转会费守恒、资金变化、合同更新和其他已签合同不变。

```sh
node scripts/football/audit-bidding.mjs
node --test tests/bidding.test.mjs
node scripts/football/audit-finance-history.mjs --years 1 --workers 8 --out artifacts/finance-history/bidding-v1-season-01
```

新生涯浏览器数据库为 `astraball-seasons-rules-v2-economy-v3-cities-v1-bidding-v1`，旧城市分配十季结果和旧浏览器数据库均保留。首版竞价仍是一次报价上限清算，买方报价和目标排序、卖方保留价格、工资/转会费共同加价比例都需继续通过长期运行校准；不能凭受控涨价案例宣称已实现长期均衡。

## 完整第一季结果

以相同初始世界运行 318 年，完成 4,057 场比赛。旧版取城市分配十季模拟的第一季；新版独立冻结源码运行。

| 指标 | 原定价 | 竞价第 1 版 |
|---|---:|---:|
| 转会笔数 | 485 | 733 |
| 最高转会费 | 1.16 亿 | 2.05 亿 |
| 最高新签周薪 | 56.16 万 | 171.78 万 |
| 全年球员工资 / 经营收入 | 31.4% | 50.8% |
| 年末俱乐部现金总额 | 316.51 亿 | 226.16 亿 |

新版 733 笔转会均保存竞价记录，其中 664 笔有至少两家有效买方。月度与季度检查通过，无负现金、人数不足或无门将警告。全量 247 项测试通过，包含支付能力、席位、确定性、转会资金守恒、自由签约与续约外部报价。

这轮只验证了一季，尚未用新版重跑十季，不能据此判定长期贫富分化、球星接班和豪门板凳深度已经合理。
