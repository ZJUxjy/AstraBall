# CA / PA 200 分制

2026-09-18

## 数值契约

CA（当前能力）、PA（潜力上限）、地方球员的简化能力、成长历史和球探预测统一使用 1–200。显示值四舍五入；成长和估值使用未取整值。

技术、身体、意识、门将的 42 项属性继续使用 1–99；体能、士气和比赛状态继续使用 0–100。球员位置权重先求属性加权平均，再由单一映射函数转换成 CA。

| 原能力 | 新 CA / PA |
| --- | --- |
| 40 | 50 |
| 60 | 90 |
| 70 | 115 |
| 75 | 130 |
| 80 | 145 |
| 85 | 160 |
| 90 | 175 |
| 94 | 185 |
| 97 | 192 |
| 99 | 200 |

140–150 对应强队常规轮换水平，160–180 为顶级球员。大于 180 的自然生成需要通过独立稀缺性筛选：约千分之一有资格获得 181–190 上限，约十万分之二有资格获得 191–200 上限；最终潜力还取决于其本身禀赋，因此实际数量会更少。指定作者潜力可直接设置至 200，用于明确设定的特殊人物和测试，不进入普通随机分布。

初始职业人口 5,432 人；未四舍五入 CA 大于 180 者为 0，显示能力大于 160 者为 226；PA 大于 180 者为 2，大于 190 者为 0。不会为凑人数强行制造传奇。

## 引擎与经济

- 比赛事件仍由具体属性计算。选人、位置适配、换人、青年赛事对抗强度和招募阈值明确使用属性单位，避免直接把 200 分值代入原来的概率公式。
- 成长用逆映射计算剩余发展空间，严格限制 CA 不超过 PA。地方联赛同样先在属性单位计算成长和实力差，再转换回 CA。
- 身价和工资 API 接收 200 分制，通过逆映射进入工资基准曲线。145 对应原 80 的薪资基准，175 对应原 90；年龄、合同剩余时间、位置稀缺性、竞价和球队支付能力继续生效。
- 俱乐部初始生成参数 quality 是内部属性基准，不作为玩家可见 CA。公开 rating / preciseRating 返回 200 分制，内部 skillRating / preciseSkill 返回属性单位。

## 旧档兼容

abilityVersion: 2 标记新标准。未标记旧档在校验前转换：

- 持久化球员 PA、地方 CA / PA、成长起点和历史、年度增幅、球探预测区间。
- 年度增幅按转换后的两个端点重新计算，不能统一乘二。
- 原始技术属性、成长包络、身份、现金、工资合同、账本、赛果、比赛种子和进行中的比赛快照保留。
- 若旧档已存在超出普通潜力限制的实际能力，保留其当前水平，PA 不低于 CA。
- 转换可重复调用但只执行一次，下一次正常保存写入新版本；历史档案读取时同样适配。未支持的能力版本明确拒绝。

## 金额与排序

所有游戏金额共用 src/format.js：小额直接显示，万元和亿元缩写，保留最多两位小数；负数、零和缺失值单独处理。单位临界点避免显示“10000万”。底层账户保持原始精度。贷款输入以万星元为单位，提交时还原成整数星元。

- 阵容：号码、姓名、位置、年龄、周薪、身价、能力、进球、助攻、分钟、体能，均可切换正反顺序。
- 引援和合同：姓名、位置、年龄、周薪、身价、能力；先筛选和排序全体，再每页显示 60 人。
- 青训：姓名、位置、年龄、周薪、能力；排序发生在分页前，不公开隐藏 PA。
- 地方名单、积分榜、财政、赛程、历史与交易等数据表格：表头按钮支持键盘和双向排序；按位置顺序、数字或日期比较，缺失值始终末尾。原排名数值保留。
- 关注、同乡、校友等人物列表：提供姓名、年龄、位置、周薪、能力排序；未知字段排在末尾。
- 财政表格通过原始数值标记排序，不解析四舍五入后的显示值。阵容和市场同样按原始金额排序。
- 导航、阵型槽位、赛事晋级树和叙事时间轴具有固定语义顺序，不作为可重排的数据榜单。
