# 青少年身体发育

青年身高、体重现在随年龄变化。青训中心和完整竞技档案显示当前体格与本季变化，月度记录和年度总结保留当时的测量值；不会公开成年目标或隐藏成熟参数。

## 模型

`bodyProfile` 在生成时保存体格锚点、成年目标和各自的成熟年龄。成年体格由独立种子生成，身高与体重有一定关联；位置影响体格先验。它不会改变技能、性格或潜力的随机序列。

早熟与晚熟复用已有的成熟偏移，改变发育时间，不自动决定最终身高或潜力高低。身高和体重分别沿平滑曲线趋向目标，达到成熟年龄后停止发育增长。身高成熟年龄为 19 加成熟偏移，体重为 22 加成熟偏移；这些是游戏设计参数，不是临床或现实球员群体拟合。

同一 ID、种子和位置从不同年龄入库，共享同一成年体格目标。正式生涯按参考日期的周年年龄计算当前体格，不依赖推进次数或刷新次数。独立 `developWeek` 对照实验沿用每年 365.25 天的年龄口径，与按周年计算的正式赛历存在微小差异。

比赛中的身体能力仍由力量、速度、弹跳等属性及已有成熟模型决定。当前比赛引擎不直接读取身高和体重；本次不另外把长高转换成属性奖励，避免重复计算成熟收益。

## 兼容

已有青年第一次接入时，以存档当天的年龄、当前身高和体重作为锚点，之后平滑增长，不回溯改写旧测量值。剩余发育最多增加 8 cm / 12 kg；已经成熟的对应指标不再增长。迁移档案持久化后不重抽。

旧存档中缺少体格记录的历史保持缺省，不补造过去的身高。迁移发生在季中时，“本季变化”只累计接入后的变化。原有静态职业球员的体格保持不变。

内部保留小数，界面身高显示整数厘米，体重与变化显示一位小数，所以某段时间显示的整数身高可能不变，但本季增长已有零点几厘米。

## 校准与验证

`npm run audit:body` 检查固定种子的 1,000 人，每人 480 个年龄点，验证单调性、成年稳定、目标边界与迁移锚点。报告位于 `artifacts/youth-development/body-calibration.json`。

| 年龄 | 平均身高（cm） | 平均体重（kg） |
| --- | ---: | ---: |
| 15 | 170.7 | 58.9 |
| 16 | 174.5 | 61.8 |
| 17 | 177.9 | 64.9 |
| 18 | 180.2 | 68.0 |
| 20 | 181.5 | 73.1 |
| 24 | 181.5 | 75.4 |

本表为游戏模型输出，不能用作现实青少年体格标准。当前曲线不模拟营养、疾病、减重、增肌计划或伤病导致的体重变化。

`npm run check` 和全部 108 项测试通过。回归覆盖纯模型、存档迁移、按日期分段与连续推进、跨季归零、历史保留、公开信息过滤和 UI 兼容。浏览器在独立测试存档中从 1 月 1 日推进到 3 月 2 日，确认身高增量 +0.4 cm、体重增量 +0.3 kg，刷新后结果一致；旧球员体格未在接入时突变。
