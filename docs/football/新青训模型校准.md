# 新青训模型校准

本实验检验游戏生成与成长机制的内部行为，**不是现实足球数据拟合**。没有预设现实潜力一定服从正态分布，也没有用更大的抽样规模替代现实数据。

## 复现

`node scripts/football/audit-youth.mjs --count 400 --seed youth-calibration-v1`

完整结果：`artifacts/youth-development/calibration.json`。players.js SHA-256：`a872e0197316f52df113102661e83aa4b622e0f9e14a6f26917b005683705c0a`。相关源码哈希见 JSON 的 sourceHashes。

固定400组球员ID及潜在参数，分别从15岁和16岁开始，模拟到28岁；各起始年龄运行三条路径。位置按现有25人名单比例取样。每条路径18岁前均为每周60分钟青年比赛、0.6训练负荷；成年后分别稳定出场90分钟/周、替补0分钟/周、过载240分钟/周并采用0.9负荷。其他条件相同，无随机伤病，不模拟选拔和退训。

16岁起步的稳定出场路径：初始CA与28岁CA相关系数0.71；可比较的球员两两排序中，26.00%在28岁时发生先后互换。这个指标说明模型允许后发进步，不是现实逆袭概率。

当前显示CA同为51的39名16岁球员，在相同培养路径下，28岁CA范围为60.15～83.74，PA范围60.61～89.43。分组包含不同位置；它说明相同总评不代表相同发展前景，不是匹配真实球员的因果研究。

## 机制检查与边界

- 全部长期路径中，发展档案和PA保持稳定，各项能力未越过自己的包络。
- CM改标为ST、GK改标为CB后保持相同训练条件，模拟至28岁属性差异最大值为0；改评分位置不会刷新成长空间。此检查不代表已实现转位置培养。
- 当前青年身高、体重按固定发展档案随年龄变化；体格不额外给比赛属性加分，因此本实验的CA对照仍隔离能力成长。体格曲线用 `npm run audit:body` 独立检查；它不代表完整生理发育模拟。
- 领域关联、初始训练积累、年龄曲线和成长速率都是游戏设计参数。训练设施差异、伤病随机事件、退出与重返职业路径不在本实验内。
- 不同年龄重新初始化与先从更小年龄逐周培养是不同实验，当前没有保证两者得到相同CA。
- 本报告中的青年比赛分钟仅作为成长曝光输入；没有运行赛程、球探判断或职业选拔模块。
