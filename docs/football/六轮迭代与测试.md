| 版本 | 改动与发现 | 场数 | 进球 | 射门 | 下一轮依据 |
| --- | --- | ---: | ---: | ---: | --- |

| V2 | 几何 xG、终结与门将分离、逆足、降低射门频率 | 1000 | 1.832 | 34.412 | 进球偏低，传球/射门结构仍需校准 |

V6 中途另运行 1200 场（`v6-calibration`），场均 2.577 球、28.503 次射门。六轮归档基准加该次校准合计 **9200 场**。这里统计的是多版本执行场次，不是 9200 个互不重复的种子。

V6 最终基准：传球 777.673、成功率 84.85%、射正 10.320、xG 2.895、犯规 24.449、黄牌 3.575、红牌 0.093、角球 6.285；平局 25.37%，0:0 占 8%，总进球至少七球占 1.23%。这是同一对名单的校准结果，不应当作全联赛分布。

## 留出验证：7000 场

使用 800000 起未用于校准的种子；每 40 场更换生成名单，并交换主客。八类场景各 500 场：均势、高水平、低水平、强弱悬殊、高压对短传、直传对低防线、窄阵对宽阵、淘汰赛。另三项属性干预各低/高两组 500 场，使用 900000 起配对种子。最终通过全部断言。详细记录在 `artifacts/football/v6/validation.json`。

均势留出结果：场均 **2.588 球、27.862 次射门、777.224 次传球、85.13% 传球成功率、24.372 次犯规、6.370 次角球**，平局率 **25.6%**。

| 干预（相关属性 ±18） | 低组 | 高组 | 检验对象 |
| --- | ---: | ---: | --- |
| 终结组合 | 1.232 | 1.614 | 被干预队场均进球 |
| 门将组合 | 1.478 | 1.036 | 对手场均进球 |
| 传球组合 | 307.026 | 360.756 | 被干预队场均成功传球 |

这些是成组属性敏感性检验，不是对每一属性独立因果效应的估计。改变能力后随机路径可以分叉，配对种子不意味着每个事件都相同。

通过区间是项目的宽松验收门槛，不是对现实联赛精确置信区间的声称：均势进球 1.9—3.6、射门 20—34、成功率 74—90%、犯规 17—33、角球 4—13、红牌 0—0.25、平局率 17—36%。现实赛事会随赛制、水平及年份改变，例如 [UEFA 2024/25 欧冠联赛阶段分析](https://www.uefa.com/uefachampionsleague/news/0296-1d000360407d-802d53438db6-1000--champions-league-goals-analysis-of-the-league-phase/)给出的场均进球为 3.26；本虚构赛事没有照搬为唯一目标。

已知需要继续校准的地方：基础能力 86 对 52 的极端差距样本，强队胜率达 99.4%。这证明能力有区分作用，但也可能放大了强弱差距，不能据此推断真实弱队爆冷率。xG 为人工公式，尚无历史数据拟合与可靠性曲线。

## 复现

在仓库根目录运行：

```sh
npm run check
npm test
MATCHES=3000 npm run audit:football
PER_CASE=500 npm run validate:football
```

后两个命令重写对应报告；核心源码哈希写进报告用于对应实际运行版本。不要用当前引擎重写旧版本快照。

复现某一归档版本的单场：

```js
// 在仓库根目录使用 node --input-type=module
import {generateTeam} from './artifacts/football/v3/players.js';
import {simulateMatch} from './artifacts/football/v3/engine.js';
const home=generateTeam({id:'h',quality:68,seed:'audit'});
const away=generateTeam({id:'a',quality:68,seed:'audit'});
console.log(simulateMatch({home,away,seed:10000,capture:false}).score);
```

归档核心不依赖 DOM。V1—V4 不具备 V5 才增加的规则，不能用最终规则回归套件直接衡量早期版本。最终版本的统计、规则和浏览器验证也不等于长期赛季平衡、真实性或性能已经完全验证。
