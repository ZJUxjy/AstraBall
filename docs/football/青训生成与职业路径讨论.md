# 青训生成与职业路径：多 Agent 讨论方案

日期：2026-09-16。本文保留最初讨论的背景和建议；年度青训、流转、观察及身体发育现已接入，最新状态见[青训系统实现](青训系统实现.md)。文中“现有实现的基础与断点”描述讨论当时版本。

三个 Agent 分别审视现实发展路径、生成与成长模型、玩家体验，并交叉讨论了潜力稳定性、位置评分偏差及球探信息。本文由主 Agent 综合代码核查与公开资料整理。以下变量、阶段划分和试验规模都是游戏设计提案，不是现实统计参数。

## 1. 核心决定

生成一批具有不同成熟进程、已有训练积累和发展特征的年轻人，让他们通过训练、比赛、观察和多轮选拔进入职业体系。

首版保留少量稳定的隐藏发展参数；实际发展随环境和经历改变；球探预期作为另一套有证据的估计更新。普通职业经历包括低级别主力、轮换、替补、换队和退出，不能只围绕巨星与失败两个结果。

十亿人实验只回答了独立正态属性按总评截取上端之后的数学分布，不能据此确定现实职业成功率、潜力分布或年龄成长曲线。尤其应明确分母：全体同龄人口、踢球儿童、注册青少年、职业学院在训球员是不同人群。

## 2. 现有实现的基础与断点

可以沿用：42 项比赛属性、按位置加权评分、分组年龄曲线、成熟偏移、学习效率、职业态度、训练与上场贡献、比赛难度匹配、伤停出勤、收益封顶以及确定性日历结算。

优先改动：

1. `generateYouthPlayer` 用潜力减固定年龄差值再加 ±3 得到当前能力，同龄人当前能力几乎泄露潜力。隐藏 `potential` 字段不足以隐藏未来。
2. 各属性围绕同一基础值独立抽样，球员容易缺少相互关联的技术特点和真实短板。
3. 成熟偏移只影响后续成长速度，没有同步塑造初始身体成熟程度；身高、体重也尚无青少年随年龄发育的过程。
4. 当前全局潜力余量取决于主位置总评。若加入位置转换，换到低评分位置可能释放额外成长空间；应先改底层成长约束。
5. 成长模块及比赛模块依赖启动时的固定球员/球队名单。年度青训、转会、租借和退役尚没有完整动态注册闭环。
6. 标准训练负荷现在是统一最优；增加按钮并不能产生有效训练决策，需接入赛程、疲劳和恢复的权衡。

代码依据：`src/football/players.js`、`src/football/data.js`、`src/competitions/development.js`、`src/competitions/runtime.js`。当前实现说明见《球员成长与校准》。

## 3. 生成模型：先有年轻人的差异，再计算总评

建议将一个球员分成三层：

| 层次 | 内容 | 变化方式 |
|---|---|---|
| 发展特征 | 技术、身体、意识的发展倾向；门将另有守门倾向；成熟进程、学习响应 | 创建时确定，首版默认稳定 |
| 实际状态 | 当前属性、训练积累、身体成熟程度、健康、位置熟悉度、成年比赛适应 | 随经历和时间变化 |
| 观察与预测 | 球探对当前水平和未来发展层级的估计、依据、置信程度 | 随有效观察更新 |

这些隐藏发展特征是用于模拟的参数，不代表现实中能测出某人不可改变的生物学上限。

### 最小参数集

在已有 `maturityShift`、`learningRate` 和人格参数基础上，外场球员先增加技术、身体、意识三个相关的发展维度，以及一个入训前训练积累参数；门将多一个守门发展维度。属性层面的细节可由固定种子产生，不必先新增 42 个互不相关的上限。

初始当前属性由发展倾向、年龄与成熟度、先前训练、位置经历以及小幅个体差异共同生成。避免再从单个潜力总分减固定年龄差。

属性应有相关性，例如停球与技术共享一部分协调/技术因素，短传与长传共享传球因素；速度与力量可以同时突出，也可以不同步，不硬编码互斥。保留专项差异，避免会传球就必定会射门，或高潜力者所有方面都强。

数学上可先用少量相关正态隐变量生成发展倾向，再映射到有边界的属性参数。它是可调整的工程起点；不要求最后当前能力或潜力总评服从单一正态分布，也不以“曲线像钟形”为验收标准。

位置首先是倾向与经验。训练和参赛可以改变熟悉度，位置评分只是对同一组属性的不同评价。改变主位置不重新抽取天赋，不直接增加属性，不刷新成长余量。

### 潜力的含义

建议逐步将单个 `potential` 从全局硬上限改为参考条件下的未来能力投影：用底层发展参数，在一组明确的训练、比赛及健康假设下估计成熟期可能水平。投影依赖位置和条件，应标明计算口径。

成长约束落在底层属性或能力组的参考发展包络与边际收益递减上；年龄曲线和训练剂量继续约束长期增长。角色变动只改变评价，不改变资源。首版不做“进球多就永久加潜力”或每赛季重抽天赋。

潜力预测变化与真实属性变化分别记录：一次球探改判，不意味着后台球员突然被加了天赋；训练进步是真实状态改变，而不是预测值更新。

## 4. 成长与职业入口：多年、多轮、多出口

以下年龄只是游戏分段，不是全球统一发展时间表。首版可从 15 岁进入可操作青训，较早的踢球经历以背景积累呈现，后续再扩展更低年龄段。

| 阶段 | 球员面临的问题 | 玩家主要决策 |
|---|---|---|
| 入训与基础培养 | 已有训练不同、身体成熟不同、位置尚可调整 | 招募、基础训练、继续观察 |
| 青年队竞争 | 优势能否在更强对手面前成立 | 青年队出场、专项训练、逐步尝试新角色 |
| 职业过渡 | 一线队位置有限，能否适应成年比赛 | 提拔、轮换、租借、低级别机会 |
| 职业立足 | 稳定出场、健康、角色和竞争决定兑现程度 | 留队、换队、调整角色、继续培养 |
| 离队或退出 | 原俱乐部不再需要，不等于所有球队都不需要 | 释放、试训、重新签约、转入半职业/业余 |

每轮选拔使用俱乐部能观察到的表现、进步趋势、成熟状态估计、位置需求、教练偏好与有限名额。AI 和玩家遵守同样的信息边界，AI 不读取隐藏发展参数直接挑“注定成功者”。

皇家晨星/远穹学院可以提供通识教育、系统训练以及选秀资格；俱乐部青训提供本地选材、青年队和一线队的连续路径。学院资源影响招生覆盖和培养条件，不是进入名校就凭空获得潜力。选秀落选者也应有地方联赛、试训等去向；具体注册资格应作为本世界规则单独制定。

岗位需求很重要。此前独立属性实验里，各位置评分均值一致，但中卫总评标准差约 3.18，右边锋约 3.64；严格超过同一门槛的比例约为 0.552% 和 1.293%。这是评分权重带来的数学差异，不能解释成现实边锋更容易产生天才。未来选拔不能只按全球统一分数排序；应结合位置基准和实际岗位需求，也不必机械保证每个位置恰好录取 1%。

青年、预备队和低级别需要产生有效上场机会。成长收益取决于参与程度、比赛难度和任务是否合适。强队训练环境好，但长期没有比赛不应总优于较低级别的稳定出场；低水平比赛也不能无限刷增长。

## 5. 真实感应体现为可理解的经历

下面是机制应允许产生的例子，不是预先分配的剧情或固定命运：

- 早熟、训练充分的少年短期更能赢得青年比赛，后来成长放缓，成为地方职业队可靠轮换。
- 身体尚未成熟、技术基础不错的少年暂时无法应付成年对抗，留青年队或合理外租后逐渐立足。
- 身体早熟且学习响应强的球员继续领先；早熟不能自动等于低潜力。
- 发育晚但训练反应一般的球员最终停留在业余水平；晚熟不能自动兑换高潜力。
- 学院的优秀青年因一线队同位置拥挤，换到更适合的球队后获得发展机会。
- 被原俱乐部释放的球员在低级别稳定踢球，数年后成为更高级别球队的实用引援。

不要为了制造故事随机加 20 点能力，或无预兆地永久毁掉大批球员。变化应有来源：持续训练、逐渐成熟、比赛经历、伤病与恢复等。普通的职业成功也值得游戏记录，不要求人人冲击顶级联赛。

## 6. 玩家信息与操作

本队的当前能力仍应足够清楚，玩家需要知道谁现在能踢。未来预测不显示确定命运，建议显示发展层级范围、判断可靠程度、观察依据与下一步建议。

示例文案：

> 发展预期：本级别主力至上级别轮换。把握较低。已观察 6 场。近期停球与决策持续改善，成年对抗样本不足。

这只是产品文案示例，场数和范围未校准。报告应区分信息不足与未来本身的不确定性；观察更多只能减少前者，不能消除后者。

球探误差需要持续性。同一日期、相同证据得到相同报告；重复打开不重新抽签。不同球探可以有稳定偏差，有新比赛、训练观察或不同水平的样本才更新判断。提高球探能力主要改善观察效率和判断质量，不直接提高球员实际天赋。

每个赛季安排少数重要决策点，比每周弹窗更合适。玩家可以查看：本季各级别出场分钟、主要角色、健康出勤、关键属性趋势、发展预期变更及依据。玩家做出合理选择，在一批球员上应有平均收益，但不能保证单个球员成才。

## 7. 实现顺序与首版边界

1. **动态球员注册与存档。** 持久化稳定 ID、生日/年龄、球员状态、所属球队与青训归属，成长和比赛从存档注册表读取。先支持新增、流转和退出，保留已有身份与履历。
2. **新青训生成。** 引入相关发展维度、不同训练积累与成熟状态，解除当前能力到潜力的近确定映射，修正与主位置绑定的成长上限。
3. **年度招募与简化比赛机会。** 青年队可以按周结算出场、对手水平和健康，不必首版为所有青年比赛运行完整逐回合引擎。保留时间、难度和分钟的因果记录。
4. **三条培养选择。** 留青训、进入一线队轮换、去适合的较低级别比赛；打通释放后的去向和重新进入途径。
5. **持续观察与年度报告。** 加入球探认知状态，让预期变化来自证据。

严重伤病后的复杂恢复、人格长期变化、复杂家庭社会网络和精细生理模拟放在后续。训练先做赛程与恢复权衡，再扩展训练菜单。高负荷不能永远更好，也不能永远更差；实际收益需看近期比赛与恢复情况。

无需保存十亿个完整球员对象。普通人口与未被关注的足球参与者可用群体规模表示；进入学院、球队、球探视野或历史记录的人才持久化，后续状态不能因被重新观察而重抽。

## 8. 下一轮实验与验收

先用几万至十几万名候选人做跨年龄实验，比继续单次扩大抽样更有用。建议初始同一批 15 岁球员模拟至 28 岁，使用固定种子、多批次重复。样本量可按结果不确定性再增加。15 岁以上的研究阶段并不代表所有现实青训从 15 岁开始。

分为两类实验：

- **培养对照：** 复制同一球员初始状态，分别给予合适级别稳定出场、强队长期替补、标准青年培养、过量赛程或伤停等条件。用于隔离机制，不能把这些复制样本当成现实中的独立球员。
- **体系演化：** 给球队真实容量、位置需求、球探认知和流转规则，让一批人经历不同机会与选拔。再加入后续年龄队列、退役及退出，观察多年人才供需。

应统计：

| 检查问题 | 观察指标 |
|---|---|
| 早期成绩是否过度决定命运 | 15/18 岁能力与 24/28 岁水平的关系、早期前列名单保留率 |
| 能否产生不同发展路径 | 发育组别的成长曲线、进步停滞/追赶、跨级别流动 |
| 玩家培养是否有效 | 相同球员不同路径的成熟能力、出场和健康差异 |
| 能否留住普通职业生态 | 各级别主力/轮换/替补数量、首次成年出场年龄、留存和退出 |
| 选拔是否误判又可纠正 | 被释放后再获职业机会的路径、球探预测误差与校准 |
| 是否存在位置公式偏差 | 分位置申请人数、岗位缺口、入选率和成长结果 |
| 长期人才是否失衡 | 每年新增/退役/离队人数、联赛能力水平是否持续膨胀 |
| 是否可以刷属性 | 改位置、重复推进、重复观察、切换训练和读档的一致性 |

现实中没有可直接观测的“真实 PA 84”作为标签，因此应尽量校准可观察结果，而非只要求隐藏潜力呈某种分布。职业的定义、地区与联赛范围应先固定，再找匹配样本；国家队和顶级学院研究不能代表所有普通球员。

## 9. 讨论中的取舍

- **固定潜力还是动态潜力：** 采用稳定的底层发展特征，培养影响实现路径，预测随证据更新。暂不采用按成绩随机增加/减少天赋的机制。
- **复杂模型还是可理解体验：** 优先少量变量产生清楚的因果，避免一开始加入几十个隐变量后无法解释与校准。
- **全球择优还是实际岗位选拔：** 全局前 1% 保留为数学对照，正式系统使用球队岗位、预算、观察与多轮去向。
- **预写晚成故事还是机制自然产生：** 允许晚熟、迟获机会和低级别再发展，不给“晚熟”标签保证成功奖励。
- **真实感还是惩罚性随机：** 用机会成本、等待和有限信息制造管理难题；突发事故应可解释、适度且允许合理应对。
