# 青训长期验证

正式比赛能够持续运行，但不能视为长期平衡完成：9个级别相对初始首发能力变化达到5分，另有位置深度和出场机会问题，需要继续校准。

本报告的20季数据为**门将深度修复前的固定版本基线**，修复后330单季回归单列，未混合数据。

本报告记录 318–337 年 **20 个完整赛季、95,180 场真实正式比赛**，以及独立的三个赛季经理情景 **14,277 场正式比赛、132 场经理入口执教**。没有替换成抽签比分或补写职业分钟。

## 口径与复现

- 每年268家俱乐部各加入3名可追踪代表青年，共804人；三人代表学院可追踪名单，青年队其余位置由稳定的背景队友参加竞争。这不是全人口职业选拔率。
- 正式比赛走生产引擎；青年比赛沿用按周排阵与分钟分配，不是完整青年比赛引擎。
- 平均首发CA用当期成长后的属性，以4-3-3选11人并按所在槽位评价。每队先计算首发11人的均值，再对同级俱乐部等权平均。结构比较暂时忽略伤停；比赛当日可用性另行记录。不是全队平均能力，也不直接等于比赛胜率。
- 首次成年正式出场年龄只统计本次生成青年；初始职业球员没有之前赛季履历。U21分钟按每场比赛当天年龄计算，包含联赛与杯赛。
- 世界全程使用默认0.6训练负荷，经理技术训练也为0.6。高负荷杯赛减量与恢复选择依专项单元测试验证，本次长跑不是三种负荷的随机对照实验。
- 只有一个固定世界和一套经理政策，不是多随机种子蒙特卡洛研究，也不证明模型已拟合现实足球。初始职业球员保留旧成长逻辑，新生代采用属性包络；不同年龄与不同生成机制混合，不能把群体CA差值直接当作潜力参数误差。

## 第13季人才定点诊断

对330年末快照的独立只读诊断：10,452名新生代中，自然位置CA≥80有119人，PA≥85有824人、PA≥90有255人。119名已成材者分别在星冠4人、开放一级50人、二级33人、三级32人，即65人仍在较低级别。已满23岁且PA≥85的384人中，103人达到CA80，120人当季正式出场不足450分钟。自由球员池最高CA为74.28。

这个定点结果提示还需检查培养机会和已签约球员的向上流动，不能直接把顶级联赛能力下降归因于PA尾部不足。PA为开发者审计读取的隐藏上界，未向游戏球探开放；此处CA按自然位置，和上方首发槽位均值不是同一汇总口径。见[原始定点诊断](../../artifacts/academy-world/talent-diagnosis-330.json)。
