# 长期审计并行执行

本次改动只改变审计执行方式。正式比赛仍调用生产 `engineSimulation`，成长、人员流转和结果提交仍使用生产入口；不减少赛程、不替换比分、不缩短比赛。

## 已完成的等价证明

对归档旧基线分别重放第1季318年和第20季337年。337年从原336年末完整快照开始。两次均完成4,759场真实正式比赛；4,689场在同日独立球队之间并行计算，70场作为各比赛日首场串行运行。提交前输入核对均无差异。

这比较的是完整状态，包括比赛结果、伤停、成长、分钟、纪律、注册历史与赛季结算，不仅是最终比分。

证据：[318年](../../artifacts/academy-worker-benchmark/parallel-pre-advance-318/result.json)、[337年](../../artifacts/academy-worker-benchmark/parallel-pre-advance-337/result.json)。使用的生产源码均来自[旧基线归档](../../artifacts/academy-world/baseline-source.json.gz)，没有读取当时正在修改的生产模块。模块恢复到临时独立目录后，每个文件先核对归档SHA。

两次记录的赛季推进与月度校验分别约30.9秒、193.6秒。计时不含初始化或读取参考快照，也没有每月压缩保存，不能直接与先前78分钟完整20季计算精确加速倍数；新规则本身也可能增加计算量。

新版v2也已完成独立首季串并行对照：4,759场、45,966,077字节完整存档，SHA同为`d67c188b414c07a0854fcfc85d621b5ce3f9bb241a8bc57309403a36cf4fb4fd`，无输入回退。此次两组使用相同季度保存设置，串行100.2秒、并行52.1秒；同机还运行经理情景与测试，不是独占硬件性能基准。见[v2完整首季证据](../../artifacts/academy-world/opportunity-serial-parity-v2/parity.json)。

## 日期内的执行顺序

1. 可选直接调用生产成长入口推进到比赛日，避免正式交互入口为回滚复制完整历史状态。
2. 当日首场仍由 `playFixture` 正常完成。
3. 为剩余比赛准备生产输入，检查本日参赛俱乐部没有重复；如有重复，全部按顺序执行。
4. 四个worker只求解各场独立比赛。主线程仍按原fixture顺序调用 `playFixture` 提交。
5. 每次提交核对刚生成的真实输入与此前worker输入逐项一致；不一致时重新用当前输入串行求解，并计入 `inputFallbacks`，不会提交过期结果。

生产代码中的事务回滚行为没有改变。审计预推进是显式选项：运行失败立即停止，失败当月内存不写入恢复点；报告标记 `partialMonthRecoverable:false`，恢复只能从最后完整检查点开始。

## 新版运行参数与恢复

```sh
node scripts/football/audit-academy-world.mjs --years 20 --workers 4 --pre-advance --checkpoint-months 3 --out artifacts/academy-world/world-opportunity-v2
```

v1因同级招募固定顺序偏置在完成5季后中止，数据另存。v2已在修复后的生产源码冻结后，从318年初始世界完整运行至337年末，状态为completed，累计95,180场。记录耗时3,671.0秒（61.2分钟），其中93,754场并行求解、1,426场串行，没有输入不一致回退。原基线约78.2分钟；新模型规则、保存频率和同机负载均不同，不能将两次总耗时直接解释为审计工具的单独加速倍数。完整结果见[20季复测报告](青训机会与流动验证.md)。

报告仍每月更新，完整检查点每三个月保存，年末额外保留独立快照。原每月 `finishDate` 与校验步骤保留，改变保存频率不改变模型边界。最终状态和显式短跑终点均保存完整检查点。`--resume` 必须使用相同源码、年数和执行参数；季度中断会从上一个季度恢复，不能把仅有报告的月份当作可恢复状态。

每次新跑会归档生产源码、审计driver、worker及指标helper。旧20季结果保留在 `world-final`，不得覆盖；新的进展文件必须使用独立目录。

## 可比指标

- `startingCA` 保留原始口径：年末成长属性、健康状态、固定4-3-3，按槽位CA计算首发均值，再对俱乐部等权汇总。
- `actualAIStartingCA` 使用当时新AI选择的阵型与首发，但同样按槽位CA计算，不能用含位置适配和轮换折扣的 `plan.score`。它是年末健康结构指标，不是逐场实际首发均值。
- 角色机会统计使用真实正式比赛分钟，包括自然位置、零分钟、少于450分钟和CA80以上仍缺乏出场的名单。
- 同年龄潜力兑现只统计新生成且未退役球员，按年末周岁及PA区间分组，报告CA、PA余量、正式分钟。CA/PA仅为描述性比例，不是真实兑现概率；隐藏PA只用于开发审计。
- 已签约球员的直接转会通过完整注册历史中 `senior→senior` 跨俱乐部迁移识别，流向按当季会员分区判定；不含自由池再签约、选秀、提拔或租借归还。事件流有长度限制，因此不单靠最后留下的 `transfer` 事件累计。

旧基线已用同一纯查询helper补算年龄×PA、角色实际分钟和迁移，保存于[基线可比指标](../../artifacts/academy-world/baseline-comparable-metrics.json)。没有对旧快照应用新AI并声称旧玩法原本已有这些机会；旧选人器未记录的角色预期留空。新指标变高本身不能替代原433指标和实际分钟的改善。
