# 青训专项生成调整

原10亿次实验显示，多项未被位置总评加权的技术属性采用近乎相同的初始公式，角球、任意球、点球的总体分布几乎重合。本轮调整专项目标、既往练习与相关能力，不把所有属性强行改成正态分布，也不重新设定整个球员池的能力档位。

## 生成机制

- 新增传球、控球、终结、防守、争顶、传中、定位球等共享专项因子。短传与长传、盘带与技术等相关属性共享部分随机因素，同时保留单项差异。因子作用于当前值与隐藏上限；它们表示倾向，不是互斥职业模板。
- 角球、任意球、点球具有不同的既往练习水平。球员随机偏向一项练习或一般训练，偏好概率受位置影响；任何外场位置都有机会具备定位球专长。
- 既往练习只影响当前属性，不抬高天赋上限。当前值仍受原有年龄、此前整体训练、成熟程度与单项上限约束。
- 门将的短传、长传、停球等技术基础采用不同的初始扣减，不再让全部技术属性统一减18分。外场球员守门专项维持原有低值分支。
- 新专项使用单独的随机流，保持既有领域、成熟度、学习效率和身体发展生成序列稳定。

模型参数属于游戏设计取值，未拟合现实青训数据库。额外的专项因素自然使总评分布略宽；本轮没有人为压低PA高分尾部。

## 对照结果

运行30,000人新旧同种子对照；15、16、17岁与10个位置的30个组合各1,000人。两组ID、seed、年龄、位置相同，未筛选前1%，未模拟职业成长。**这次不是重跑10亿人**，原10亿报告和源码快照保持原样。

| 指标 | 调整前 | 调整后 |
|---|---:|---:|
| 平均CA | 50.739 | 50.747 |
| CA标准差 | 4.904 | 5.080 |
| 平均PA | 70.978 | 70.986 |
| PA标准差 | 9.595 | 9.717 |
| 外场角球均值 | 48.481 | 45.507 |
| 外场任意球均值 | 48.535 | 43.197 |
| 外场点球均值 | 48.521 | 48.984 |
| 外场短传／长传相关 | 0.603 | 0.662 |
| 外场盘带／技术相关 | 0.623 | 0.687 |
| 外场短传／射门相关 | 0.566 | 0.473 |

全体CA均值增加0.009，PA均值增加0.007；各位置CA、PA均值差均小于0.06分。专项特点增强，没有显著抬高整个青训池的能力。

外场任意球低于40分的比例由8.66%变为33.66%，角球由8.73%变为21.82%；点球至少60分的比例由3.24%变为4.84%。这些只是同一数值阈值下的设计对照，不表示现实球员达到某种熟练等级的比例。每项属性仍具有连续差异，并不把球员直接划分成“会”或“不会”。

定位球专项未进入当前位置总评权重，因此只看CA、PA不足以评估改动。既往练习也会降低部分跨专项相关性，例如射门与点球从0.611变为0.591，这符合当前新增独立练习因素的机制，但不是现实相关系数的估计。

## 存档与边界

新生代档案标记为`generationVersion: 3`，保留既有`growthProfile.version: 1`数据结构。现存球员保留已经存储的属性、上限与身体发展资料；本轮不重生成旧球员，也不重置观察报告。

专项因子通过最终属性和上限留存，不向玩家公开隐藏参数。本轮调整生成阶段的既往练习，没有增加可操作的单项定位球训练。成年发展仍使用现有训练领域和比赛曝光机制。

## 验证

`npm run check`、全部 119 项测试和长期成长校准通过。回归包含旧存档继续成长、专项相关性、定位球差异、门将技术区别及历史实验来源保护。

原十亿实验只对应调整前生成器；相关脚本现在会在来源不符时拒绝覆盖或重新标注旧结果。32 位随机种子机制没有在本轮更换，种子碰撞限制仍然存在。
