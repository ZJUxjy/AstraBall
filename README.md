# AstraBall · 世界、球员与比赛

一款以俱乐部经理兼主教练为玩家身份的足球管理原型。参考 fm_lite 的球员生涯与联赛归属思路，以及 FibelNFL 的学院、选秀和球星卡分层；代码独立，不读取或修改参考项目存档。

## 运行

需要 Node.js 22 或更新版本。无需安装依赖。

```sh
npm run dev
```

打开 http://127.0.0.1:4318 。

```sh
npm run check
npm test
```

## 已实现

- V18 已整合空间与传球线路、位置职责、对手临场调整，以及合同、工资和转会市场；保留原有青训、选秀、租借和身体发育。整合范围与验收见 [主分支合并记录](docs/engine-evolution/主分支合并.md)。

- 接手六套体系任意一家俱乐部；经理首页显示赛季目标、积分排名、下一场对手、伤停待办与近期赛果。
- 正式比赛赛前布阵、临场战术、换人和委托至终场；赛前布置与比赛中途进度本地保存，刷新可继续。
- 比赛日自动停在本队开赛前，其他球队自动比赛；执教球队、战术和首发偏好跨年延续。
- 球员随赛历成长：按年龄、位置、训练、出场和伤停分别发展；本队个人训练、近期成长曲线及年度记录随赛季保存。
- 青训中心：年度新人、相关联的隐藏发展禀赋、发展观察区间、地方青训提拔、真实租借、皇家学院选秀、自由签约与退役补位。
- 青年身高和体重随年龄发育，档案展示本季变化，旧青年存档从当前体格平滑接入。
- 俱乐部逐年收支：工资、转会、签字费、解约、运营与工资超额税，以及转播、赞助、商业、比赛日、奖金和股东注资；各赛区采用工资软线和滚动财政审查，大都会三个平级联赛政策一致。
- 第 3 版经济：收入按商业基础、球场及转播池独立计算，豪门经营收入达到十亿星元，转会费按能力、年龄与合同定价；现实参照、验证与存档兼容见 [经济量级与贫富差距](docs/finance/经济量级与贫富差距.md)。
- 跨赛季历史档案：各项冠军、赛事 MVP、积分榜、球员数据榜、球队累计战绩、顶级联赛战绩和指定对手交手记录。

- 四个大区、36 个省、108 座重要城市、六套赛事体系、9 个常规联赛、217 家俱乐部。
- 四个培养机构，普通家庭、皇室与皇室分支示例。
- 四十名现役或退役人物；288—317 年共三十届完整状元记录。
- 可点击球员卡：出生地、学院、家庭、选秀、俱乐部、职业事件。
- 城市／省份／大区范围切换，同级别／同联赛／全部现役同乡筛选。
- 校友、同届学员、父子关系、退役人物和相邻年份选秀探索。
- 当前浏览器本地关注名单。

## 目前边界

这是内容、交互与比赛模拟原型。已接入个人训练与持续成长、全年赛历、赛季存档、升降级和跨年，以及年度青训、提拔、租借、选秀、有偿转会、自由签约、退役和俱乐部财政。青年比赛目前按周模拟成长机会，尚无完整青年联赛；未接入营养与训练引起的体重变化和完整动态世界模拟。比赛为逐事件概率模型，场地为位置示意；尚无 22 人连续物理运动或基于职业赛事数据拟合的 xG。正式赛季与赛果本地保存；独立友谊赛刷新清除。数据中的地名、皇室姓氏、纪年、具体人口、球员与成就均为草案；新增青年已有基于经历的发展预测，尚无覆盖全体球员属性的完整球探迷雾。卡面采用球衣图形，尚无人物肖像。

各级俱乐部与竞技名单已补齐；校友和家庭关系仍是局部样本。皇室政治权限仍待讨论；全球冠军杯名额与选秀资格已写入赛事规则。初稿采用全球招生、普通家庭可有亲属、固定世界结合后续存档生成的方向；已接入固定地形样例、确定性行政区适配和多语系球员生成，尚未实现动态世界历史生成。

## 星球地图

世界图鉴打开星球地图，首页默认进入经理模式。支持大区、省份、城市定位、地名搜索、缩放、拖动，以及行政／地形／交通图层。地理设定与生成规则见 `世界地理设定.md`。地理数据和人物档案共用稳定 ID。

- `src/geography/catalog.js`：地区、省市、地形与水系名录。
- `src/geography/generate.js`：确定性地理生成器。
- `src/geography/topology.js`：固定地形入口。
- `scripts/import-azgaar.mjs`：Azgaar 实际样例导入器，运行 `npm run import:map` 可复现；来源与许可见 `third_party/azgaar/README.md`。
- `src/geography/geometry.js`：共享几何计算。
- `src/atlas.js`、`src/atlas.css`：地图交互与界面。
- `tests/geography.test.mjs`：空间、人口、年代、连通性与深链接检查。
